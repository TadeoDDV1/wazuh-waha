# Project Guidelines & Rules

## Autonomous Execution & Permissions
- **Proactive changes**: Always perform code edits, file updates, creation of files, and shell commands directly without stopping to ask for permission or confirmation.
- **Autonomous troubleshooting**: When debugging or making improvements, test, fix, and verify changes autonomously.
- **Minimal friction**: Report results and summaries clearly once changes are implemented, rather than asking "Do you want me to proceed?" beforehand.
